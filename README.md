# SatSpec Artifact

Due to non-disclosure agreement (NDA) restrictions, this artifact is provided as an encrypted `7z` archive.

## Extraction Instructions

### 1. Install 7-Zip

```bash
sudo apt update
sudo apt install p7zip-full -y
```

### 2. Extract the Archive

```bash
7z x [7z archived file path]
```

When prompted, enter the password.
